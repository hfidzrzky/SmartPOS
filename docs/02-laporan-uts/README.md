## Panduan Konversi ke PDF / Cetak Laporan UTS

Untuk mengubah berkas `LAPORAN_UTUH_UTS_SMARTPOS.md` menjadi berkas PDF resmi:
1. **Menggunakan VS Code (Paling Cepat & Rapi)**:
   - Pasang ekstensi **Markdown PDF** (oleh yzane) di VS Code.
   - Buka berkas `LAPORAN_UTUH_UTS_SMARTPOS.md`.
   - Klik kanan di editor $\rightarrow$ pilih **Markdown PDF: Export (pdf)**.
2. **Menggunakan Browser (Chrome / Edge)**:
   - Buka berkas Markdown di GitHub atau Markdown Viewer.
   - Tekan `Ctrl + P` $\rightarrow$ Simpan sebagai PDF (*Save as PDF*).
3. **Menggunakan Microsoft Word**:
   - Salin isi berkas markdown ke Microsoft Word, lalu simpan sebagai format `.docx` atau ekspor ke `.pdf`.
